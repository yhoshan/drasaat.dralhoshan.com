# استيراد كتب المداخل العلمية

يقع كل كتاب مدخل في فئة مستقلة باسم **المداخل العلمية**، ويظهر تلقائياً في مربع «المداخل» داخل الهيرو، كما يدخل ضمن إجمالي المواد. يقبل الاستيراد ملف Excel أو CSV أو JSON؛ ويستخدم الورقة الأولى في ملف Excel.

| الحقل | المطلوب | أمثلة للعناوين المقبولة |
|---|---|---|
| العنوان | إلزامي | `العنوان`، `عنوان`، `title`، `اسم الكتاب` |
| المؤلف | اختياري | `المؤلف`، `اسم المؤلف`، `author` |
| الروابط | اختياري | `رابط تيليجرام`، `رابط جوجل درايف`، `رابط مباشر` |
| التصنيف | اختياري | `التصنيف` أو `القسم`؛ والقيمة الافتراضية هي «المداخل العلمية» |
| البيانات الببليوغرافية | اختياري | `المحقق`، `الناشر`، `السنة`، `عدد الصفحات`، `حجم الملف` |

بعد رفع الملف إلى مساحة العمل، يُنفَّذ الأمر التالي من جذر المشروع:

```bash
pnpm import:entries /المسار/إلى/ملف-المداخل.xlsx
```

تتولى الأداة كشف التكرار بحسب العنوان والرابط، وتعيين `درجة = مدخل علمي` و`نوع المادة = مدخل`، ثم تعيد بناء ملفَي `items.json` و`stats.json`. ولا تُضاف الصفوف الخالية من العنوان.
