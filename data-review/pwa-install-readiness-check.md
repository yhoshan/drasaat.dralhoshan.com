# فحص جاهزية تثبيت PWA

أجري الفحص على معاينة HTTPS للمشروع بعد تحديث تعريف PWA. تظهر البيانات التالية كما يقرأها المتصفح:

| العنصر | النتيجة |
|---|---|
| اسم التطبيق في manifest | الدراسات |
| الاسم المختصر في manifest | الدراسات |
| اسم Apple Web App | الدراسات |
| أيقونة 192×192 | متاحة عبر مسار التخزين الرسمي |
| أيقونة 512×512 | متاحة عبر مسار التخزين الرسمي |
| Apple Touch Icon | يشير إلى الأيقونة الرسمية 512×512 |
| سياق HTTPS | متاح |
| دعم Service Worker | متاح في المتصفح |
| Service Worker مسجل في المشروع | غير موجود |

يعني ذلك أن تسمية «الدراسات» والأيقونة الرسمية جاهزتان لمسار **إضافة إلى الشاشة الرئيسية** في iPhone/iPad Safari. أما تثبيت التطبيق بصيغة PWA الكاملة في Chrome على Android فلا يكتمل ما دام لا يوجد Service Worker مسجل. لم يُضف Service Worker لأن نطاق المهمة كان اختبار الجاهزية فقط.

كما أن التحقق جرى في معاينة التطوير؛ يلزم حفظ ونشر التغيير قبل أن يرى الهاتف العام الأيقونة والتسمية الجديدتين على النطاق المنشور.
